# 진행 상태 중심 제작 화면

## 목표와 범위

상시 노출되는 상세 기록·작업 강도 설정을 줄이고 실제 실행·최근 활동·응답 대기·중지 상태를
화면 앞쪽에서 확인한다. 모델·강도는 관제 대화에서 시작 전에 정하며 이미 합의한 선택은 유지한다.
앱의 제작 시작은 현재 설정을 짧게 확인한 뒤 실행한다. 기록·사용량은 관리 안에서 요청할 때 연다.

`MakerApp`의 현재 조회 시각과 기존 Run 실행 제어·Task 활동 관측을 읽는 진행 표시를 추가한다.
실제 활동 시각과 단순 조회 성공을 구분하며, 현재 시도·호출과 다른 관측은 사용하지 않는다.
90초간 활동 변화가 없으면 대기 안내를, 15초 이상 상태 조회가 없으면 확인 지연을 표시한다.
시간 경과만으로 중단을 단정하지 않는다. 실제 잠금·중지·사용자 확인 상태가 우선한다.

`MakerRunControls`의 강도 패널 진입을 제거하고 기록을 관리로 옮긴다. 시작 확인은 당시 계획에
고정하고 최신 상태를 다시 검사한다. 긴 실행 요청 중에도 상태 조회·중지를 독립적으로 허용한다.
공개 RPC·저장 형식·실행 설정·승인 경계·Git 동작은 변경하지 않는다.

## 검증

현재/이전 시도와 호출, 활동 없는 반복 응답, 조회 지연, 실제 중지와 사용자 확인을 검사한다.
시작 확인·취소·계획 변경·실행 중 중지·기존 승인과 모델 설정 보존을 관련 테스트로 확인한다.
renderer 전체 검사·타입 검사·프로덕션 빌드를 실행한다. 실화면 확인은 임시 예제 데이터로
검증하며 실제 사용자 프로젝트·인증·실행에는 접근하지 않는다. Mac 실행과 배포는 별도다.

## 결과

- `상세 기록·작업 설정` 진입과 해당 화면의 강도 패널을 제거했다. 작업 기록·사용량·검사 기록은
  관리 안에서 접어서 제공한다. 관제 프롬프트는 시작 전 설정 확인과 기존 합의 보존을 안내한다.
- 앱 시작 확인은 당시 계획·배정 모델에 고정하고 취소·최신 계획 검사 뒤 실행한다. 긴 요청 중
  상태 재조회·현재 실행 ID의 중지 요청을 독립적으로 처리하며 확인창은 실행 요청 전에 닫는다.
- `MakerProgress`에서 현재 시도·호출에 맞는 활동과 신호를 구분하고, 경과·조회 지연·실제 중지·
  재개 가능·사용자 확인을 표시한다. 검사 단계도 현재 검증 시도의 기록만 사용한다.
- renderer 전체 331개, 타입 검사·Electron/renderer 프로덕션 빌드 통과. 새로운 검사에는 과거 관측,
  새 신호만 있는 상태, 조회 지연, 중지·대기 구분, 시작 확인·취소·계획 변경·실행 중 중지가 포함된다.
- React 정적 렌더링으로 예제 마크업을 생성했다. 실제 화면을 보기 위한 in-app browser의
  로컬 `file:` 주소 열기는 브라우저 보안 정책에 차단되어 실화면·좁은 화면 검증은 완료하지 못했다.
  해당 제한을 우회하지 않았다. Mac 실행·실제 사용자 작업·배포 ZIP 반영은 수행하지 않았다.
- Python 변경이 없어 Python 검사는 재실행하지 않았다. 기존 로컬 UI·MCP 수정과 사용량 패널을
  보존했다. 배포 ZIP 발행은 별도다.
