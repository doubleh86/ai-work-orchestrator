# v0.7.0 Windows 앱·MCP ZIP 릴리스

## 목표와 범위

공개 소스의 Claude API 키 연결, 보관함 분리·짧은 제목과 트레이 종료를 Windows x64
앱 ZIP과 MCP 전용 ZIP으로 제공한다. 기존 v0.6.0 릴리스·태그·산출물은 유지한다.
제품·lock·Python 버전을 0.7.0으로 맞추고 ZIP 안내의 종료 방법을 트레이 메뉴 기준으로 수정한다.
비공개 개발 원본과 실제 사용자 설정·프로젝트는 변경하지 않는다.

## 빌드와 검증

공개 저장소의 전용 환경과 커밋된 제품 소스로 정식 패키징한다. 공개 릴리스 절차에 따라
의존성·타입·renderer/Python 회귀 검사, 프로덕션 빌드와 동봉 backend의 desktop RPC·
MCP 기획/제어·등록/업데이트를 검사한다. Windows x64·버전·소스 commit·필수 라이선스,
ZIP 무결성·SHA256과 인증/상태 제외·개인정보·비밀정보를 확인한다.

격리 사용자 영역에서 배포 ZIP의 backend와 Electron 실행을 확인한다. 실제 인증·유료 AI
호출·사용자 프로젝트·macOS/Android 실행과 코드 서명 검증은 이 Windows 릴리스에 포함하지 않는다.
앱/MCP ZIP과 각각의 SHA256을 새 태그 v0.7.0에 첨부하고, GitHub의 자산 크기·digest와
태그 commit을 대조한 뒤 공개한다. 실제 검사 결과와 미검증 범위는 릴리스 노트에 기록한다.

## 진행

공개 main의 기능 구현과 관련 검사는 완료되어 있다. 이번 릴리스는 버전·문서·패키징 안내만
변경하며 기존 바이너리를 덮어쓰지 않는다. 릴리스 결과는
[v0.7.0](https://github.com/doubleh86/ai-work-orchestrator/releases/tag/v0.7.0)에 기록한다.

전용 환경의 의존성 설치·audit(취약점 0), 타입·renderer 352개·Python 구문 검사를 통과했다.
Python 전체 1,421개 중 1,415개와 하위 사례 396개가 통과했고 환경 조건 5개는 제외됐다.
빈 저장소 검사 1개는 저장소 내부 임시 폴더가 상위 Git을 인식해 상태 분류가 달랐다.
Git 탐색 상한을 임시 폴더로 제한한 개별 재검사에서 통과했다. 제품·테스트 코드는 바꾸지 않았다.
공개 소스 235개 파일과 기존 이력 10개 커밋의 개인정보·비밀정보 점검도 통과했다.
