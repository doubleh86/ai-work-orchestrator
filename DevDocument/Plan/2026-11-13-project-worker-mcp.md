# 프로젝트별 외부 작업 도구 연결 공개

## 목표와 범위

검증된 프로젝트별 MCP 연결 기능을 공개 소스에 반영한다. stdio·Streamable HTTP 정의와
registry schema 4, Codex·Claude 실행 전달, 연결 확인과 공유 도구 대기를 포함한다.
현재 공개 의존성·라이선스·버전과 기존 공개 이력을 유지하며 원본 이력을 가져오지 않는다.
사용자 자료·인증·내부 운영 기록과 임시 산출물은 제외한다. 바이너리 릴리스는 범위 밖이다.

## 검증 방법

동일 기능 코드의 기존 관련 검증 결과를 재사용하고 공개용 차이는 별도로 확인한다.
타입·구문·diff, 선택한 registry 설정 테스트와 문서 참조를 확인한다. 공개 대상 파일과
새 commit의 비밀정보·개인 식별정보·작성자·원격 상태를 점검한 뒤 main만 push한다.
전체 테스트·빌드·실제 사용자 MCP·Unity·유료 AI 호출은 실행하지 않는다.

## 진행과 결과

제품·테스트 18개 파일이 검증한 원본과 같음을 확인했다. 기존 연결 파싱·SDK 초기 연결·
공유 도구 대기와 renderer 검사 결과를 재사용했다. 공개 소스의 TypeScript 타입·수정 Python
구문·diff 확인과 registry/CLI/SDK 설정 소비 경계의 선택 테스트 8개가 통과했다.
공개 checkout의 Python 환경에 pytest가 없어 기존 pytest 환경으로 공개 소스 경로를 명시해
검사했으며 새 의존성을 설치하지 않았다. 공개 의존성·버전·라이선스·제외 규칙은 보존했다.
README에 소스 기능과 기존 ZIP의 차이를 짧게 안내했다. 실제 Unity 에디터와 Claude 실계정
도구 호출·전체 테스트·빌드·패키징은 실행하지 않았다.
