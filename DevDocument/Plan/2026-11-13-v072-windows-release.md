# v0.7.2 Windows ZIP 릴리스

## 목표와 범위

공개 main의 프로젝트별 외부 MCP 연결 기능을 Windows x64 앱·MCP 전용 ZIP으로 배포한다.
제품 버전 네 곳과 짧은 사용 안내를 갱신하고, 검증한 공개 commit에서 새로 빌드한다.
기존 릴리스·태그·산출물과 개발 원본을 보존한다. 버전 태그와 ZIP 두 개·SHA256 두 개를
새 GitHub Release에 게시한다. 다른 OS·Unity 설치나 실제 사용자 계정 작업은 포함하지 않는다.

## 검증 방법

현재 바이너리 릴리스 절차에 따라 의존성 설치·감사, 타입·구문·전체 관련 언어 테스트와
빌드를 확인한다. 패키징 내부 빌드와 실행 검사를 재사용하고 통과한 검사를 반복하지 않는다.
인증·등록 프로젝트·앱 상태는 임시 사용자 디렉터리로 격리한다. ZIP 무결성·체크섬·버전과
소스 commit·라이선스·포함 runtime·배포 파일의 민감정보를 확인하고 원격 업로드 결과를 대조한다.

## 진행과 결과

v0.7.2 태그가 비어 있고 기존 v0.7.1이 최신임을 확인했다. 버전·빌드·검증 범위를 기록했다.
실제 AI 인증·Unity 에디터 기능·새 PC 인수·코드 서명은 검증 완료로 주장하지 않는다.
