# v0.6.0 Windows 앱·MCP ZIP 릴리스

## 목표와 범위

새 제작 UI와 외부 AI 앱의 MCP 제어를 포함한 Windows x64 앱 ZIP과 MCP 전용 ZIP을 발행한다.
기존 v0.5.0 태그·산출물은 보존하고 새 v0.6.0의 제품·Python·lock 버전을 일치시킨다.
ZIP의 사용 안내를 새 채팅·연결 프롬프트와 MCP 등록 도우미 기준으로 갱신한다.

## 빌드와 검증

기존 개발 환경을 변경하지 않는 별도 Python 빌드 환경을 사용한다. 검증된 공개 소스 commit에서
정식 빌드하고 source commit·제품 버전·x64·라이선스·runtime·SHA256과 ZIP 무결성을 확인한다.
동봉 backend의 desktop RPC, 조회·외부 기획·제어 MCP 모드와 등록·업데이트를 임시 사용자 영역에서
검사한다. GUI 실행도 별도 registry와 사용자 설정 영역에서 확인하며 실제 인증·프로젝트를 사용하지 않는다.
실제 Codex/Claude 대화·사용자 프로젝트 실행·다른 OS 검증과 코드 서명 여부는 별도로 기록한다.

소스·이력·산출물의 비밀정보와 로컬 경로를 점검한 후 공개 main과 v0.6.0 태그,
GitHub Release에 앱 ZIP·MCP ZIP·각 SHA256을 올린다. 비공개 원본과 기존 사용자 설정은 유지한다.
