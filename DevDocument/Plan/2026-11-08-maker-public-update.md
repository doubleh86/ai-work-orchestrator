# 제작 UI와 외부 AI 제어 공개 소스 갱신

## 목표와 범위

공개 main에 외부 앱의 MCP 기획·제어와 오케스트레이터의 여러 작업 AI 실행 흐름을 반영한다.
새 제작 UI, 태스크별 모델·사용자 확인·결과 실행을 제공하고 구 UI 전용 소스·테스트·의존성을 제거한다.
기존 공개 이력·라이선스·패키징 고지·보안 수정된 의존성과 공개 버전은 유지한다.
README는 최신 소스 실행과 사용 순서만 짧게 안내한다. 기존 바이너리 릴리스는 이번 소스 갱신과 분리한다.

## 공개·호환 경계

제품 소스·테스트와 공개 문서만 반영한다. 개인·사내 식별정보, 실제 환경 경로, 인증·실행 상태,
내부 제작 기록과 비공개 Git 이력은 포함하지 않는다. 테스트에는 일반화한 독립 임시 프로젝트를 사용한다.
공통 인증·실행·승인·복구, 공개 RPC와 기존 저장 데이터의 호환성은 유지한다.

## 검증

공개 복사본에서 의존성 설치·audit, 타입 검사, renderer 전체 검사·빌드와 Python 전체 검사를 수행한다.
파일·문서 참조·secret 검사·커밋 메타데이터를 확인한 뒤 공개 main에 일반 commit으로 추가한다.
푸시 후 원격 HEAD와 tree를 대조한다. 실제 AI 호출·사용자 인증과 새 바이너리 배포는 수행하지 않는다.

## 결과

- 구 UI 소스·스타일과 전용 검사 파일 146개를 제거하고 새 제작 화면과 MCP 계획·제어를 반영했다.
  공개용 패키징 고지, 라이선스와 외부 Codex runtime 사용을 유지했다.
- Electron 44.10.1·Vite 8.3.5 등 기존 공개 의존성 보안 수정을 보존했다. 미사용 Markdown 관련
  의존성을 제거하고 `npm ci`, Electron runtime 설치, audit를 완료했다. 취약점은 0건이다.
- 공개 복사본의 타입 검사·renderer 전체 322개·Electron/renderer 빌드·Python compileall을 통과했다.
- Python 전체 1,398개를 빠짐없이 선택해 검사했다. 재검증 포함 1,396개·하위 사례 396개가 통과했고,
  심볼릭 링크와 플랫폼별 EACCES 검사 2개는 환경 조건에 따라 제외됐다.
- 처음 사용한 깊은 Windows 임시 경로에서 파일 경로 길이로 4개가 실패해 짧은 독립 경로에서 확인했다.
  분할 검사 도구의 multiprocessing 재진입 보호 누락으로 실패했던 사용량 검사 1개도 표준 pytest
  개별 실행으로 통과했다. 이 과정에서 제품 코드는 수정하지 않았다.
- 공개 파일 214개의 민감 경로·개인/사내 식별정보와 문서 링크를 확인했다. 예제 사용자 경로는
  보안 입력 차단 검사의 가짜 값으로 분류했다. Gitleaks 파일·공개 이력 검사에서 탐지는 0건이다.
- 개발 원본의 HEAD·index·원격 설정과 tracked 파일 hash를 대조해 보존을 확인했다.
  기존 공개 이력 위의 일반 소스 commit으로 갱신하며 실제 사용자 인증·AI 호출·새 OS 실행과
  새 바이너리 릴리스 검증을 의미하지 않는다. 기존 v0.5.0 ZIP은 이전 UI로 유지한다.
