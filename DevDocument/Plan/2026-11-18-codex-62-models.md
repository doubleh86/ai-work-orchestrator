# Codex 6.2 모델 지원

## 목표와 범위

- `gpt-6.2-sol`, `gpt-6.2-astra`를 선택 목록에 추가하고 새 자동 배정에 사용한다.
- 일반 구현은 Sol, 높은 위험·민감 계약·설계·의존/충돌 작업과 기획·원인 분석은 Astra를 사용한다.
- 절약/균형 모드의 작고 명확한 수정은 기존 Luna/Terra를 유지한다.
- SDK의 무지정 기본값과 신규 설정은 6.2 Sol로 맞춘다. 명시적 모델/추론은 그대로 전달한다.
- 수동·legacy 선택과 시작된 정책 snapshot은 변경하지 않는다. 기존 6.1 Sol 승격 기록도 검증 가능해야 한다.
- 후속 요청: `gpt-6-astra`, `gpt-6.1-sol`은 신규 선택에서 제외한다. 프로젝트 설정에 있어도 후보에 다시 넣지 않고,
  해당 설정을 복원하는 빈 모델 선택도 제공하지 않는다. 기존 실행/SDK 호환과 저장 데이터는 유지한다.
- 설정·선택 규칙·SDK·표시와 관련 테스트만 수정한다. SDK 의존성, 저장 형식, 승인·Git 경계는 유지한다.

## 검증

- 수정 Python 구문 검사, TypeScript typecheck, diff 확인.
- 자동 배정·정책 복원/수동 보존, 설정/선택 RPC, SDK 모델 전달 관련 기존 테스트를 선택한다.
- 실제 계정 호출·전체 테스트·빌드·패키징·공개 저장소 반영은 이번 범위에 포함하지 않는다.

## 근거

- [공식 모델 변경 기록](https://developers.openai.com/api/docs/changelog)
- [6.2 전환 가이드](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6.2-astra)
- Codex SDK는 모델 ID 문자열을 전달한다. 앱은 모델 미지원 오류를 이전 모델 성공으로 숨기지 않는다.

## 진행과 결과

- 구현 완료: 신규 모델 프리셋·자동 배정·SDK 무지정 기본값·신규 설정·기획 프롬프트와 UI 자동 선택 표시를 갱신했다.
- README의 현재 선택 정책과 과거 실계정 확인 기록을 구분했다. SDK 의존성은 변경하지 않았다.
- 수동/legacy 선택, 시작된 6.1 Sol 정책과 이전 6.1 Sol 승격 기록이 복원·검증되는 것을 확인했다.
- `npm run typecheck` 통과. 수정 Python 11개 파일 `py_compile`과 `git diff --check` 통과.
- 자동 모델 선택 파일과 설정 3개 케이스, 모델 선택 RPC, SDK 직접/자동 전달·오류 케이스를 선택해 검증했다.
  첫 실행 43개 케이스·76개 subtest가 통과했고, 설계 작업이 작은 수정 분기로 먼저 진입한 subtest 2개는
  중요도 판단을 앞당겨 수정 후 해당 케이스와 작은 수정 케이스를 재확인했다.
- 기획/실행 정책 binding 관련 파일을 확인했고, 신규 승인 계획 fixture는 현재 Sol/Astra 조합에 맞췄다.
  이전 6.1 저장 작업을 재개하는 fixture는 유지했다. 실패했던 기획 1개 및 실행 8개 케이스는 수정 후 통과했다.
- 마지막 승격 검증 변경은 이전 6.1 기록 허용과 변조 차단 2개 케이스·4개 subtest로 확인했다.
- 전체 테스트·빌드·실계정 호출·GUI 실행은 수행하지 않았다. 실제 계정의 모델 접근 권한은 이번 검증으로 확정하지 않는다.
- 후속 제외 완료: 6 Astra·6.1 Sol은 프리셋과 설정 기반 후보에서 제외했다. 기존 설정값을 되살리는
  빈 모델 선택도 기존 조회 규칙에 따라 숨긴다. 채팅 지시 예시와 README를 현재 모델로 갱신했다.
- 후속 검증: 설정 후보·기획/실행 모델 RPC·제외된 설정의 자동 선택 차단·기존 6.1 정책/승격 복원
  관련 7개 케이스 통과. 변경 Python 4개 파일 `py_compile` 및 diff 검사 통과.
  TypeScript 변경이 없어 앞선 typecheck는 반복하지 않았다.

## 후속 작업: 사용할 모델 설정

- 6 Astra·6.1 Sol의 고정 제외를 사용자 설정으로 대체한다.
- 작업 AI의 Codex 카드에서 사용할 모델을 체크하고 저장한다. 초기값은 6.2 Sol/Astra, 6.1 Terra, 6 Luna다.
  6 Astra와 6.1 Sol은 필요할 때 켤 수 있다. 앱 공통 설정으로 저장하며 최소 하나를 선택한다.
- Codex 선택 목록, 신규 자동 배정/SDK 기본값, 모델을 바꿔 시도하는 복구는 같은 설정을 읽는다.
  활성 모델 중 역할에 맞는 후보를 선택한다. 지원하지 않는 자동 추론 강도는 선택 모델 범위에 맞춘다.
- 기존 실행이 저장한 프로필과 프로젝트의 명시적 설정을 유지한다. 신규 선택과 기존 저장 프로필의 복원을 구분한다.
- 앱 설정 JSON은 원자적으로 저장한다. 저장 요청은 편집을 시작할 때 읽은 모델 목록과 대조한다.
- 검증은 설정 저장/재조회, 읽기와 저장 RPC, 후보 반영, 자동 배정, 기존 실행 복원과 정적 검사로 한정한다.
- `codex_model_preferences`가 앱 공통 파일을 관리한다. 애플리케이션의 조회·저장 메서드를
  RPC가 노출하고, 코어가 신규 선택 시 설정을 읽는다.

구현 후 관련 51개 테스트와 102개 하위 케이스가 통과했다. 옛 모델만 켠 상태에서 설정 저장·재조회,
후보 목록, 기획 모델 안내, 자동 배정과 SDK 전달을 확인했다. 빈 선택·알 수 없는 모델과 오래된 저장 요청은
거부했고 저장된 실행 및 수동 계획은 복원했다. TypeScript 타입 검사, Python 구문 검사와 diff 검사도 통과했다.
GUI 실행과 실계정 모델 호출은 수행하지 않았다.
