# 창 닫기와 트레이 종료 분리

## 목표와 범위

창의 닫기 버튼은 창만 숨기고 작업·연결·알림·미저장 화면을 유지한다.
트레이는 창 열기와 종료를 제공하며, 종료는 기존 미저장 확인과 Python 프로세스 정리를 따른다.
Electron main의 창 생명주기에서 트레이 표시·닫기 제어를 작은 모듈로 분리한다.
아이콘은 모듈에 포함해 개발 실행과 기존 패키징에서 같은 파일을 사용한다.

트레이를 만들지 못하면 사용자에게 알리고 창 닫기를 가로채지 않는다. 실제 종료 의도는
`before-quit`에서 구분하고, 미저장 확인에서 취소하면 숨김 동작을 복원한다. backend 정리는
창 닫기가 모두 승인된 뒤 한 번만 수행하고 끝나면 트레이를 제거한다.
RPC·Pipeline·저장 형식·Git 작업은 변경하지 않는다.

## 검증

관련 main 프로세스 테스트에서 닫기→숨김·같은 창 복원·작업 유지, 종료 취소·재시도,
중복 종료 중 한 번의 backend 정리·아이콘 제거와 트레이 실패 시 닫기 허용을 확인한다.
기존 알림 클릭 복원 검사와 타입 검사만 실행한다. 사용자 앱·실제 작업은 종료하지 않는다.

## 결과

`DesktopTray`를 추가하고 main의 창 닫기·복원·종료 의도를 연결했다. 숨김 중에는
기존 창과 IPC·backend·알림을 유지하며, 실제 종료 정리의 중복 실행을 막는다.
트레이는 Windows 클릭과 열기 메뉴로 복원하고 macOS는 메뉴 막대용 아이콘을 사용한다.

타입 검사와 `notification-window-activation.test.cjs`의 관련 10개 검사를 통과했다.
내장 PNG의 크기·압축 해제·청크 체크섬을 확인했다. 실제 OS 트레이 조작·패키징은
사용 중인 앱과 작업을 건드리지 않기 위해 실행하지 않았다.
